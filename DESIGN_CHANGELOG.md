# ClamKeep — журнал редизайна

Релиз 1.10.0 (ветка `redesign/native-ui`). Бизнес-логика не менялась: включение/выключение режима, `caffeinate`, IPC помощника, таймер, слежение за приложением и загрузками, ключи `UserDefaults`, версия помощника (1.4.0) и шорткаты ⌘W / ⌘S / ⌘L / ⌘D / ⌘Q. Аудит «до» — в `DESIGN_AUDIT.md`.

## Что изменено и почему

| Было | Стало | Зачем |
|---|---|---|
| Цветной не-template значок, белый 75% в выключенном состоянии | Template-глиф: контур = выкл., заливка = вкл., кольцо = экрану можно гаснуть; цвет — опция | Виден в светлой и тёмной строке меню, уважает «Увеличить контраст» и выделение |
| Wake Mode — обычный пункт с `[ON]` | Шапка: статус, время, переключатель `NSSwitch`, метрики; под ней пункт «Включить / Выключить бодрствование ⌘W» | Главное действие заметно, состояние видно сразу, режим доступен с клавиатуры и VoiceOver |
| Состояние = зелёный жирный текст + «ON» в колонке шорткатов | Системные галочки, шорткаты на своих местах | Нативно, читается VoiceOver, один способ показать состояние |
| Исключения не связаны с Wake Mode | Сразу под шапкой, неактивны, когда режим выключен | Понятна зависимость |
| 12 пресетов таймера (5…60 мин) | 15, 30, 45 мин, 1, 2, 4 ч + «Своё время…» | Короче список, полезнее диапазон; сохранённое значение вне списка показывается и отмечено |
| Settings ▸ Language ▸ / Icon ▸ | Окно настроек ⌘, с тремя вкладками | Одна точка входа вместо трёх уровней вложенности |
| About — алерт с простынёй changelog | Вкладка «О программе» | Коротко: версия, слоган, ссылки |
| Модальный алерт установки помощника, ошибка — сырой текст AppleScript | Окно настройки: загрузка, успех, понятная ошибка с «Повторить» и «Подробности»; баннер в меню | Не блокирует запуск, всегда есть следующий шаг; отмена пароля — не ошибка |
| Включение без помощника молча откатывалось | Если помощника нет, переключатель открывает окно настройки; если помощник отклонил включение (с любого пути — таймер, загрузки, приложение), ClamKeep перепроверяет его и предлагает установку | Пользователь понимает, что делать; медленный ответ или неудачная переустановка не блокируют режим |
| Алерт таймера с полями на фреймах | Панель: поля + `Stepper`, время окончания, inline-валидация | Нельзя ввести 0, видно, когда режим выключится |
| Выход без «не спрашивать» | Разрушительная кнопка «Выйти и выключить» + «Больше не спрашивать» | Подтверждение только там, где оно нужно, и его можно отключить |
| Нет главного меню | Невидимое главное меню | В окнах работают ⌘W, ⌘Q, ⌘, и редактирование текста |
| Жёсткие RGB-цвета | Только системные семантические цвета | Тёмная тема, акцентный цвет, контраст |
| Растровая иконка из `generate_icon.swift` | Многослойная Icon Composer иконка | Варианты dark / clear / tinted, чёткость в любом размере |

## Дизайн-система — `Sources/DesignSystem/`

**Токены (`Tokens.swift`)**
- `DS.Spacing`: 2 / 4 / 8 / 12 / 16 / 20 / 24 / 32, `menuInset` 14.
- `DS.Radius`: 4 / 6 / 10 / 14.
- `DS.Elevation`: hairline 1, selectionRing 2 — без декоративных теней.
- `DS.Opacity`: disabled 0.35, secondary 0.6, subtleFill 0.08, tintedFill 0.12, tintedStroke 0.28.
- `DS.Motion`: 0.12 / 0.2 / 0.3 c, при «Уменьшить движение» — 0.
- `DS.Size`: ширина шапки меню 340, глиф 18, точка статуса 8, плитка 104, окно настроек 480, иконка 96 / 64.

**Цвета (`Colors.swift`)** — `DS.Palette` и `Color.ds*`: background, surface, elevatedSurface, textPrimary / Secondary / Tertiary, separator, accent (системный), success, warning, danger, inactive.

**Типографика (`Typography.swift`)** — SF Pro через стили текста: title 15 semibold, headline 13 semibold, body 13, callout 12, caption 11, footnote 10 (минимум), numeric (моноширинные цифры), technical (моноширинный), плюс AppKit-шрифты для меню и метрик.

**Компоненты (`Components.swift`, `WindowPresenter.swift`)**
- Кнопки: `primaryAction()` (prominent + Return), `cancelAction()` (Escape), `secondaryAction()`; разрушительная — `hasDestructiveAction` в алерте выхода.
- `SectionHeader`, `StatusBanner` (info / success / warning / error), `LoadingState`, `ErrorState`, `IconTile`.
- `WindowPresenter` — окна SwiftUI в агентском приложении: одно окно на идентификатор, активация, закрытие.
- AppKit: `StatusHeaderView` с ячейками метрик (`Sources/MenuBar/`).

Компоненты из исходного запроса, которым нет места в утилите строки меню (Sidebar, SearchField, TabBar, Toast, Sheet, Popover), не создавались, чтобы не оставлять мёртвый код. Вкладки — нативный `NSTabViewController` в стиле toolbar.

## Иконки

### Главная иконка — «Шов крышки»
Закрытый MacBook спереди (крышка в перспективе, основание), светящийся шов и статус-точка с кольцами на тёмно-синем фоне. Исходник: `Design/AppIcon/AppIcon.icon` (Icon Composer: заливка + слои `lid.svg`, `base.svg`, `seam.svg`, `pulse.svg`, без текста и масок). Вариант dark задан явно; clear и tinted система строит из слоёв. Превью: `Design/AppIcon/previews/` (`default`, `dark`, `clear-light`, `clear-dark`, `tinted-light`, `tinted-dark`, `overview`, `size-16…128`).

### Значки строки меню
В macOS нет `CFBundleAlternateIcons`, а смена иконки бандла в рантайме ломает подпись — поэтому альтернативные иконки ClamKeep — это стили значка строки меню. Идентификаторы сохранены, выбор пользователей не сбрасывается.

| Старое имя | Новое имя | Концепция |
|---|---|---|
| — | `lid` · Lid / Крышка / Қақпақ | Закрытый ноутбук, как на главной иконке. По умолчанию для новых установок |
| `moon` · Moon / Полумесяц | `moon` · Moon / Луна / Ай | Работа ночью |
| `bolt` · Bolt / Молния | `bolt` · Bolt / Энергия / Қуат | Энергия, активность |
| `eye` · Eye / Глаз | `eye` · Eye / Глаз / Көз | «Не спит» |
| `coffee` · Coffee / Кофе | `coffee` · Coffee / Кофе / Кофе | Бодрость |
| `plain` · Shield / Щит | `plain` · Shield / Щит / Қалқан | Защита от сна |

Все стили — SF Symbols одного веса (кроме `lid`, нарисованного в той же сетке), в трёх состояниях: выкл., вкл., вкл. + экрану можно гаснуть. Опция «Подсвечивать цветом» включена у обновившихся (сохраняет привычный зелёный / оранжевый) и выключена у новых установок.

## Как проверить

Сборка и превью:
```bash
SKIP_INSTALL=1 ./build.sh          # сборка в build/, /Applications не трогается
./Scripts/snapshot.sh              # PNG шапки, настроек, онбординга, таймера → build/snapshots
open Design/AppIcon/AppIcon.icon   # Icon Composer: переключение Default / Dark / Clear / Tinted
```

Ручной чек-лист (сначала закройте установленный ClamKeep — при выходе он выключает режим):
1. Запуск: при отсутствии помощника открывается окно настройки; «Не сейчас» закрывает его, в шапке меню остаётся баннер «Установить…».
2. Шапка: переключатель включает и выключает режим, время идёт каждую секунду; пункт «Включить / Выключить бодрствование» и ⌘W делают то же, до пункта можно дойти стрелками.
3. «Разрешить сон дисплея» / «Разрешить автоблокировку»: неактивны при выключенном режиме, галочка ставится и снимается, значок получает кольцо.
4. Загрузки, «Не засыпать, пока работает приложение» (иконки приложений, пустое состояние), «Выключить через» (пресеты, своё время, перезапуск приложения сохраняет остаток).
5. Настройки ⌘,: вход в систему, статистика (шапка меняется сразу), язык (меню, окна и вкладки переключаются), значок (6 стилей, цвет), помощник (переустановка, отмена пароля → без ошибки, ошибка → «Повторить»).
6. Свой таймер: Tab между полями, стрелки степперов, Return — запуск, Escape — отмена, 0:00 → подсказка.
7. Выход при активном режиме: «Выйти и выключить» выделена как разрушительная, «Больше не спрашивать» отключает вопрос (включается обратно в настройках).
8. Светлая и тёмная тема, разные акцентные цвета, «Увеличить контраст», «Уменьшить движение».
9. Иконка в Finder, Spotlight, Launchpad / Приложениях и при смене стиля иконок в «Системных настройках → Внешний вид» (dark / clear / tinted).

## Ограничения и рекомендации
- Меню строки меню я не мог прокликать сам: проверка шла через сборку, снапшоты всех окон и состояний (light / dark, EN / RU / KK) и рендер иконки системой. Ручной прогон по чек-листу выше обязателен.
- Превью clear / tinted отрендерены через IconServices; финальный вид зависит от настроек пользователя (цвет тонировки, обои).
- Сборка из исходников теперь требует Xcode 26+ (для `actool` с `.icon`); в старых macOS 13–25 используется `Assets.car` / `AppIcon.icns`, собранные тем же инструментом.
- Стрелками до `NSSwitch` в шапке не дойти (ограничение custom view в `NSMenu`), поэтому под шапкой есть обычный пункт «Включить / Выключить бодрствование ⌘W».
- `docs/screenshot.png` — превью из отрендеренных окон и шапки (`Scripts/snapshot.sh`), а не снимок экрана; после релиза стоит заменить его настоящим скриншотом меню.
- Следующая итерация: перевести локализацию на String Catalog.
