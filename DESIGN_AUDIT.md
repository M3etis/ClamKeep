# ClamKeep — аудит UI/UX (версия 1.9.0)

## UI-стек
- Чистый **AppKit**: `NSStatusItem` + `NSMenu`, приложение-агент (`LSUIElement`, без Dock).
- Сборка — `swiftc` через `build.sh`, без Xcode-проекта и Asset Catalog.
- Иконка приложения — PNG, нарисованный `generate_icon.swift`, → `iconutil` → `AppIcon.icns`.
- Локализация — ручной `enum L` (EN / RU / KK) в `Sources/Localizable.swift`.

## Инвентарь интерфейса
| Элемент | Код | Состояние |
|---|---|---|
| Значок в строке меню | `IconRenderer.swift` | Нарисован вручную, цвета зашиты; 5 стилей |
| Шапка с метриками | `SystemMetricsHeader.swift` | Custom view 380×80 |
| Главное меню | `AppDelegate.setupMenu()` | 14 пунктов, 2 подменю + Settings с 2 вложенными |
| Установка помощника | `setupDaemon()` | Модальный `NSAlert` при запуске |
| Ошибка установки | `executeInstallScript()` | `NSAlert` с сырым текстом AppleScript |
| Своё время таймера | `promptCustomTimer()` | `NSAlert` с полями на фреймах |
| О программе | `showAbout()` | `NSAlert` с длинным changelog |
| Подтверждение выхода | `quitApp()` | `NSAlert` |
| Пустое состояние | подменю «Активное приложение» | «Нет запущенных приложений» |
| Окна, тосты, загрузка | — | Отсутствуют |

## Проблемы

### Визуальная иерархия
- Главное действие (Wake Mode) выглядит так же, как второстепенные пункты.
- Активность передаётся тремя способами одновременно: жирным шрифтом, зелёным текстом и словом «ON» в колонке шорткатов.
- Исключения Display Sleep / Auto Lock не связаны визуально с Wake Mode, хотя зависят от него.

### Несогласованность
- Цвета зашиты (`NSColor(srgbRed:)`, `NSColor(red:)`), часть из них плохо читается: неактивный значок — белый 75%, он теряется в светлой строке меню.
- Два разных способа показывать состояние: `[ON]/[OFF]` у трёх пунктов и зелёный жирный текст у остальных.
- Размеры шрифтов в шапке (11/14 pt) не связаны со шрифтом меню.
- Значок не template: не реагирует на «Увеличить контраст», тонированную строку меню и выделение.

### Избыточные и неочевидные действия
- «ON» в колонке шорткатов подменяет шорткат: пункт теряет подсказку ⌘-клавиши, VoiceOver читает «ON» как сочетание клавиш.
- 12 пресетов таймера с шагом 5 минут — длинный список с почти одинаковыми вариантами.
- About — простыня текста в алерте, дублирующая README.

### Навигация и информационная архитектура
- Настройки — три уровня вложенности (Settings ▸ Language ▸ …, Settings ▸ Icon ▸ …).
- Нет отдельного места для статуса помощника: если он не установлен, Wake Mode тихо откатывается.

### Пустые, загрузочные и ошибочные состояния
- Нет состояния загрузки при установке помощника — пользователь не знает, что происходит после ввода пароля.
- Ошибка показывает сырой текст AppleScript, без повтора и пояснения.
- Своё время таймера не валидируется (0 часов 0 минут молча выключает таймер).

### Доступность, клавиатура, тёмная тема, локализация
- Значок без accessibility-описания состояния.
- Алерт таймера: поля без связи с подписями, нет пошагового ввода (`Stepper`).
- Тёмная тема держится на ручных цветах, а не на системных семантических.
- Ошибки в RU-строках («пока идет загрузка», «пока активное приложение»).
- При выходе нет «Больше не спрашивать».

### Иконки
- В macOS нет `CFBundleAlternateIcons`, а подмена иконки бандла в рантайме меняет подписанный `.app` и ломает подпись. Dock-иконки у агентского приложения нет.
- Поэтому роль альтернативных иконок играют **стили значка строки меню**: `moon`, `bolt`, `eye`, `coffee`, `plain` (ключ `ClamKeepIconStyle`). Нарисованы разной толщиной штриха и разной плотностью.
- Главная иконка — растр без вариантов для тёмной, clear и tinted тем macOS 26+.

## План редизайна (по приоритетам)
1. **Дизайн-система**: токены, семантические цвета, типографика, компоненты — только системные динамические значения.
2. **Значок строки меню**: template-глифы одного веса, контур/заливка для состояния, новый стиль `lid`, опция цвета при активности.
3. **Меню**: шапка со статусом, `NSSwitch` для Wake Mode и метриками; системные галочки; исключения с отступом под Wake Mode; короткий список пресетов таймера; баннер «Нужен помощник».
4. **Окно настроек** (General / Menu Bar Icon / About) вместо вложенных подменю и алерта About.
5. **Онбординг помощника** с загрузкой, понятной ошибкой и повтором; **панель своего таймера** с валидацией; алерт выхода с «Больше не спрашивать».
6. **Главная иконка** (Icon Composer, концепт «Шов крышки») с вариантами default / dark / clear / tinted и fallback `.icns`.
