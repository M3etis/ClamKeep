Questions & answers

Is it safe to run a MacBook with the lid closed?

Yes. When the lid closes, the built-in screen turns off in hardware; ClamKeep only stops the system from sleeping. Give the Mac some airflow and avoid heavy loads in a tight bag — the Temp tile helps you keep an eye on it.

Why does it ask for an administrator password?

Keeping a Mac awake with the lid closed needs a system power setting (pmset). ClamKeep installs a tiny launchd helper once; after that every toggle is passwordless. The helper accepts only an allowlist of commands, and only from your user account.

Do I need a charger or an external display?

No. Unlike the standard macOS clamshell mode, ClamKeep keeps the Mac awake on battery and without an external monitor.

How does it affect battery life?

While Wake Mode is on, the Mac uses power as if it were open (minus the screen when the lid is closed). Use the Auto-off Timer so a session never runs longer than you need.

What happens when I quit ClamKeep?

Wake Mode is turned off before the app quits, so your Mac returns to standard sleep behaviour, and the display-sleep and auto-lock settings are restored.

Which Macs are supported?

Any Mac on macOS 13 Ventura or later — ClamKeep is a universal binary for Apple Silicon and Intel.

Is ClamKeep free?

Yes. Download the DMG from GitHub Releases — the source code is on GitHub too.
