Keep your Mac awake

ClamKeep lives in the menu bar. Wake Mode holds the system, the display, and auto-lock — then you can re-enable Display Sleep or Auto Lock as exceptions. Turning it off ends the entire session.

Features

Everything at a glance — plain language, no power jargon.

Wake Mode

Everything at once: keeps your Mac awake with the lid closed, keeps the screen on, and delays auto-lock. On enable those holds are automatic; on disable the whole session ends. Shows ON / OFF.

Display Sleep

Manual exception. ON — screen can turn off while Wake Mode is on. OFF — screen stays on (default on every new session).

Auto Lock

Manual exception. ON — Mac can lock after idle. OFF — delayed (default on every new session). Manual lock (⌃⌘Q) is always immediate.

Don't Sleep During Downloads

Standing policy: holds wake for download processes and recent activity in your Downloads folder.

Don't Sleep While Active App…

Keeps wake on while a selected app runs. When it quits, only that reason is cleared.

Auto-off Timer

5–60 minute presets or custom hours:minutes. The menu header shows a live countdown.

Wake reasons

manual / downloads / watched app — one source ending does not cancel the others.

Extras

EN / RU / KK, launch at login, five icon styles, universal binary, passwordless helper.

Behavior

How each state treats the display, auto lock, and a closed lid.

State Display Auto lock Lid closed
Wake Mode ON (default) Screen stays on Delayed Screen off (hardware), system awake
Display Sleep ON Display may sleep Delayed Screen off (hardware), system awake
Auto Lock ON Screen stays on (unless Display Sleep also on) Normal after idle; manual lock immediate Screen off (hardware), system awake
Wake Mode OFF Standard macOS Standard macOS Standard macOS
+ Auto-off Timer Header countdown; session ends at 00:00:00

  • Wake Mode off cancels all other options (timer, downloads, watched app, exceptions)
  • Fixed Wake Mode toggle reliability (helper IPC races, stale results)
  • Auto-off timer restores remaining time after relaunch
  • Hardened helper (v1.4.0): singleton, authenticated IPC, allowlist, injection-safe

  • Active options: green title + ON in the system shortcut column
